## 可借鉴的设计点

| 设计 | 为什么这么做 |
|------|-------------|
| `ui_filter` 禁区过滤 | 回放宏时落在按钮区的点击一律不发，避免误触回城/打卡 |
| `battle_pause` | 走位途中遇敌就暂停回放，打完回野外后**重置时间基准**再继续，避免剩余动作被压成瞬间连发 |
| 一次上膛，不反复点 | 遇敌开关只点一次；先观察 15 秒，自己进了战斗就说明本来就开着 |
| 三态判定（True/False/None） | 位置读不出时返回 **None**，调用方一律不动手；老版本把“读不出”当归“不在”，整夜空转 44 次 |
| 像素判据代替 OCR | 地图是否打开只看顶部金线是否命中（开 17/17，关 0~1/17），比读「世界地图」四个字稳 |
| 动作后复查 | 点 NPC 后先看人在不在走，走到位再点第二下，不原地连点 |
| 失败即停 | 回城/卖货/进洞每段都有重试上限，到顶就停下报错，绝不硬走 |
